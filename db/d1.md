# ER-диаграмма (Chen notation)

```mermaid
erDiagram
    PERSON {
        string id PK "xs:ID — уникальный идентификатор"
        string first_name "Имя"
        string last_name "Фамилия"
        string gender "male | female | unknown"
    }

    PERSON ||--o| PERSON : "MARRIED_TO (0..1 : 0..1)"

    PERSON ||--o{ PARENT_LINK : "as_parent"
    PERSON ||--o{ PARENT_LINK : "as_child"
    PARENT_LINK {
        string parent_id FK "-> PERSON.id"
        string child_id FK "-> PERSON.id"
        string parent_role "father | mother"
    }

    PERSON ||--o{ SIBLING_LINK : "person_ref"
    PERSON ||--o{ SIBLING_LINK : "sibling_ref"
    SIBLING_LINK {
        string person_id FK "-> PERSON.id"
        string sibling_id FK "-> PERSON.id"
        string sibling_type "brother | sister"
    }
```

## Таблица атрибутов PERSON

| атрибут | домен | ограничение |
|---------|-------|-------------|
| id | VARCHAR(50) | NOT NULL, PRIMARY KEY |
| first_name | VARCHAR(250) | NULL |
| last_name | VARCHAR(250) | NULL |
| gender | ENUM('M','F','U') | NULL, CHECK (gender IN ('M','F','U')) |

## Доменные ограничения для связей

- **MARRIED_TO (0..1 : 0..1)**: супруги разного пола (если gender известен); связь симметрична
- **PARENT_LINK**: у ребёнка не более 2 родителей; отец → gender='M', мать → gender='F'; связь "родитель → ребёнок" имеет кардинальность 0..N : 0..2
- **SIBLING_LINK**: симметричная связь (если A sibling B, то B sibling A); кардинальность 0..N : 0..N
