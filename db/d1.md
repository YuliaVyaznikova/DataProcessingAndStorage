# ER-диаграмма (Chen notation)

```
  (first_name)       (last_name)        (gender)         (id)
        │                 │                 │              │
        └─────┬───────────┴─────────────────┴──────────────┘
              │
              |    ┌───────────┐
              └────│  PERSON   │<──────────────────────┐
                   └─────┬─────┘                       │
                         │                             │
     ┌───────────────────┼────────────────────┐        │
     │                   │                    │        │
    0..1                0..N                 0..N      │
     |                   |                    |        |
     v                   v                    v        │ 
 /──────────\        /─────────\        /──────────\   │
│ MARRIED_TO │      │ PARENT_OF │      │ SIBLING_OF │  │
 \──────────/        \─────────/        \──────────/   │
     │                    │                   │        │
    0..1                0..2                0..N       │
     │                    │                   │        │
     └────────────────────┴───────────────────┘        │
                          │                            │
                          └────────────────────────────┘
```

## связи и кардинальности

| связь | описание | кардинальность |
|-------|----------|----------------|
| MARRIED_TO | супруг(а) | 0..1 : 0..1 |
| PARENT_OF | родитель -> ребёнок | 0..N : 0..2 |
| SIBLING_OF | брат/сестра | 0..N : 0..N |

## атрибуты PERSON

| атрибут | домен | ограничение |
|---------|-------|-------------|
| id | VARCHAR(50) | NOT NULL, PRIMARY KEY |
| first_name | VARCHAR(250) | NULL, длина <= 250 |
| last_name | VARCHAR(250) | NULL, длина <= 250 |
| gender | ENUM('M','F') | NULL, CHECK (gender IN ('M','F')) |

## доменные ограничения для связей

- MARRIED_TO: супруги разного пола (если gender известен)
- PARENT_OF: 
  - отец -> gender = 'M'
  - мать -> gender = 'F'
  - у ребёнка не более 2 родителей
- SIBLING_OF: симметричная связь (если A sibling B, то B sibling A)
